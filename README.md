## Project

### Severe Injuries in Texas Logistics Companies

Analyzed 517 OSHA severe injury reports involving Texas logistics companies from January 2015 through November 2025. Used Python and pandas to clean and explore the data, and created visualizations to examine accident types, hospitalizations, amputations, inspections, and incident trends.

The accident type and reason categories were AI-assisted interpretations of incident narratives. They are not official OSHA categories or confirmed causes.

[View the project on GitHub](https://github.com/RezaPaseban1991/texas-logistics-injury-analysis)
